# 记账本 · 纯本地离线记账 PWA

一个极轻量的中文记账应用：无账号、无服务器、无广告，所有数据只存在你手机本地。

## 功能

- **记一笔**：支出 / 收入，9 个支出分类 + 5 个收入分类，大数字键盘快速输入，可选日期和备注，支持修改、删除
- **明细**：按月浏览，按天分组显示，月支出 / 收入 / 结余汇总
- **预算**：设置月度预算，进度条实时显示；用掉 80% 和超支时分别提醒（首页横幅 + 记账后 Toast），并给出"建议日均可用"
- **统计**：按周 / 月 / 年查看——支出分类占比环形图、收支趋势柱状图（点击图表可查看具体数值）、分类明细表
- **外观**：浅色 / 深色 / 跟随系统
- **数据**：导出 CSV（Excel 可直接打开）、导出 / 恢复完整 JSON 备份

## 在手机上使用

### 方式一：最简单（无需任何账号和环境）

1. 把 `index.html` 这一个文件传到手机（微信文件传输助手 / QQ / 数据线均可）
2. 用手机上的 **Chrome 浏览器**打开它（用"打开方式"选择 Chrome）
3. 完成。所有功能可用，数据自动保存在手机本地

> 限制：直接打开文件时不能"安装"到主屏幕（没有独立图标），可以先把网址加入书签。
> **注意**：这种方式的记录存在 Chrome 的本地存储里，卸载 Chrome 或清理浏览器数据会丢失，请务必每月到「设置 → 数据备份」导出一次备份。

### 方式二：完整 APP 体验（推荐，免费）

把整个文件夹免费托管到 GitHub Pages（约 10 分钟）：

1. 注册 / 登录 [github.com](https://github.com)，新建一个仓库（Public，如 `jizhang`）
2. 把本文件夹里的 `index.html`、`manifest.json`、`sw.js`、`icon.svg`、`icon-*.png` 全部上传到仓库
3. 仓库 Settings → Pages → Source 选 `main` 分支 → Save
4. 等一两分钟，用手机 Chrome 打开 `https://你的用户名.github.io/jizhang/`
5. 浏览器菜单里点 **"添加到主屏幕 / 安装应用"** —— 桌面上就会出现带图标的"记账"APP，全屏运行、完全离线可用

> 换手机迁移：在新手机装好 APP 后，用旧手机导出 JSON 备份传过去，在「设置 → 从备份恢复」导入即可。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用（界面 + 逻辑 + 图表），单文件，可直接打开 |
| `manifest.json` | PWA 应用信息（名称、图标等） |
| `sw.js` | Service Worker，离线缓存 |
| `icon.svg` / `icon-*.png` | 应用图标 |
| `gen-icons.js` | 图标生成脚本（零依赖，`node gen-icons.js` 重新生成，平时可删） |

## 数据安全

- 数据以 JSON 形式存在浏览器 `localStorage`（键名 `jz-db-v1`），不上传任何服务器
- 定期备份：设置 → 导出完整备份（JSON），把文件存到网盘或电脑
- CSV 适合在电脑上用 Excel 查看分析

## 自定义分类

打开 `index.html` 搜索 `CATS`，按现有格式增删条目即可（`slot` 取 1–8 对应不同颜色，0 为灰色，`icon` 是 emoji）。
